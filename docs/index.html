Each curve component holds a piecewise-constant instantaneous forward rate, so its discount factor is D(T) = exp(−∫0T f) and its derivative with respect to node i is ∂D/∂fi = −D · wi, where wi is the length of node i's bucket inside [0, T]. The funding curve is SOFR-1B-FLAT = SOFR times its own spread factor, so by the product rule the SOFR block of its gradient is Dspread · ∂DSOFR/∂f and the spread block is DSOFR · ∂Dspread/∂s. The fixed-accrual cashflow pays C = notional × accrual on T, so PV = C · Dfunding(T) and its risk is C times that gradient.

The two step functions and the buckets that matter for the 2026-10-02 payment

Each dashed block is one node's bucket inside [0, T] and the shaded part is that bucket's share of the integral the discount factor is built from; the width of the block is the bucket length wi, which is also the node's gradient weight. The third SOFR node starts after the payment date and carries no risk; the first spread node carries risk although its spread is zero.
